# IRONFRONT · 1936

Браузерная глобальная стратегия в реальном времени, вдохновлённая жанром Hearts of Iron. Самостоятельный игровой прототип: историческая карта, 479 захватываемых городов и операции по городским областям.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm. Python 3 нужен только для обновления исходной карты.

```sh
npm ci
npm run dev
```

Команды выполняются из папки с `package.json` (в облачной среде: `/workspace/hoi4`). `npm run build` создаёт production-сборку в `dist`; `npm run preview -- --port 4173` запускает её для проверки. Серверная часть, ключи API и внешняя база данных не требуются. Карта, городские области и шрифты поставляются локально; после сборки игре не нужен доступ к внешним сервисам.

В облачной среде для установки можно использовать `npm ci --cache /tmp/hoi4-npm-cache`.

## Обновление скачанной игры в Windows

Остановите сервер сочетанием Ctrl+C. Скачайте новый ZIP репозитория и распакуйте его в папку игры. Откройте терминал в папке с `package.json`:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте адрес, выведенный сервером (обычно `http://localhost:5173`). `npm.cmd` работает в PowerShell без изменения политики выполнения сценариев. Сохранение находится в браузере, а не в папке проекта; используйте тот же браузер и адрес сервера.

## Управление

- Страна выбирается в левом верхнем углу; это начинает новую кампанию.
- **Пробел** или кнопка ▶ переключают паузу. Клавиши **1–5** меняют скорость. На скорости 1× за реальную секунду проходит 6 игровых часов.
- Время влияет на движение, бой, подготовку войск, исследования и пополнение ресурсов. Во время паузы можно отдавать приказы.
- Выберите подразделения слева или на карте и нажмите на город или его область. Для атаки сначала объявите войну в дипломатии.
- Пехота, артиллерия и танки движутся через свои и союзные городские области и атакуют города на линии фронта. Перескочить через вражеские области нельзя.
- Для морского вторжения нужен флот, доступный порт отправления и порт назначения (до 6 500 км). Наземные связи не проходят через море или чужие страны; Восточная Пруссия требует доступа через Польшу либо морской переброски. Маршруты упрощены.
- Истребители и бомбардировщики действуют в радиусе 2 500 км. Корабли поддерживают операции в портовых городах. Без сухопутных войск город захватить нельзя.
- Военная мощь зависит от количества, здоровья, организации, технологий и топлива. Противник защищается и контратакует каждые 72 игровых часа.
- Производство резервирует людей и снаряжение. Одновременно готовятся до 6 подразделений. Отмена возвращает людей и 75% снаряжения.
- Доступны исследования вооружения, промышленности и авиационной доктрины; одновременно исследуется одна технология.
- Отношения +60 позволяют заключить союз. Объявление войны стоит 50 влияния и уменьшает стабильность на 3%.
- Кампания автоматически сохраняется каждые 5 секунд в `localStorage`. Сохранение и загрузка доступны через меню. Загрузка всегда ставит время на паузу.
- Перетаскивание перемещает карту, колесо меняет масштаб. Справа доступны политический, военный и дипломатический слои, масштабирование, переход к своей стране и обзор мира.

## Города и захват

- На карте включён слой «Города и области». Точки обозначают города, звёзды — столицы; приблизьте карту для названий. Слой можно отключить кнопкой с меткой города.
- Нажатие на точку города или его область открывает сведения: текущий владелец, очки победы, промышленность, порт и гарнизон. Города выбранной страны также перечислены справа.
- После объявления войны выберите войска и нажмите на нужный город. Приказ выполняется в реальном времени. Во время паузы приказ принимается, но войска и бой не движутся.
- Гарнизон и находящиеся в городе подразделения защищают только свою область. Захват Зальцбурга не передаёт Вену или всю Австрию. Цвет и штриховка области показывают смену контроля.
- Захват передаёт промышленные объекты города новому владельцу; контратака может вернуть город и заводы. Повторные захваты не создают заводы из ничего.
- Полный контроль над территорией страны наступает после захвата всех её городских областей. Государство капитулирует, когда у него не осталось ни одного города, включая зависимые владения.
- Новые войска появляются в подконтрольном городе; корабли строятся в подконтрольном порту. Захваченный порт позволяет строить флот даже стране, которая начинала без выхода к морю. Если подходящие города/порты потеряны, подготовка приостанавливается.
- Старые сохранения автоматически переносятся на схему v2: сохраняются время, ресурсы, исследования и контроль ранее захваченных стран. Старые приказы и сражения уровня страны сбрасываются, войска располагаются в ближайших городах; приказы нужно отдать заново. Новые сохранения сохраняют отдельные города и маршруты.

## Историческая карта

Источник: **CShapes 2.0**, Nils B. Weidmann, Guy Schvitz, Luc Girardin; вариант Gleditsch–Ward (GW), срез **1 января 1936 года**, с зависимыми территориями. В карте 170 территорий и 69 независимых государств. Австрия и Чехословакия независимы; показаны Восточная Пруссия, восточные границы Польши и европейские колониальные владения.

CShapes — исследовательский набор с собственной кодировкой признания государств. Некоторые непризнанные, спорные и фактически подконтрольные образования (например, Маньчжоу-го) не выделены отдельно. Отображение не является утверждением об исторической принадлежности спорных территорий. Численность армий, экономика, идеологии, флаги и ход войны упрощены: это игровой баланс, а не реконструкция исторических событий.

Границы городских областей — **игровое разбиение по ближайшим городам (диаграмма Вороного в проекции Меркатора), обрезанное по историческому контуру страны**, а не копия административного деления 1936 года или провинций HOI4. В каталог включены 479 реальных городов с координатами; для ряда городов используются исторические названия (Кёнигсберг, Бреслау, Ленинград, Сталинград, Батавия и др.). Набор крупных городов и столиц представительский, а не полный перечень населённых пунктов мира. Некоторые точки портовых городов находятся у края упрощённой береговой линии CShapes.

Исходный пакет: <https://github.com/cran/cshapes>, commit `54840534d9a82cfd01caf1021f85933e701e8318`. Для генерации отобраны записи по датам, приведены направления колец к формату D3, координаты округлены до 4 знаков и вычислены соседние территории по топологии. Каталог дополнительных городов и корректировки столиц находятся в `src/data/city-catalog.js`; метаданные городов и граф маршрутов генерируются в `src/data/cities.json`.

Воспроизводимое обновление карты и городских областей из того же источника (проверяет SHA-256):

```sh
python3 scripts/fetch-map.py
```

Только пересоздать городские области из уже поставляемой карты (без сети):

```sh
npm run map:regions
```

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

21 тест симуляции проверяет паузу, затраты и завершение подготовки, отмену, исследования, войну, авиационную поддержку, дипломатию, ответ противника, историческую географию, отдельный захват/отбитие городов, границы городских областей, наземные маршруты, захваченные порты и перенос старых сохранений. Браузерные тесты Playwright проверяют время, все роды войск, производство, исследования, сохранение, приказы, масштаб, выбор страны, мобильный интерфейс и захват Зальцбурга с сохранением австрийского контроля над Веной.

Браузерные тесты используют Chromium из `/usr/bin/chromium`. Другой путь можно указать переменной `BROWSER_EXECUTABLE`. Для системы без Chromium установите браузер и укажите путь к нему. Playwright запускает сервер самостоятельно, если он ещё не запущен.
