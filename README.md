# IRONFRONT · 1936

Браузерная глобальная стратегия в реальном времени, вдохновлённая жанром Hearts of Iron. Самостоятельный игровой прототип: историческая карта, условный баланс и упрощённые операции на уровне государств.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm. Python 3 нужен только для обновления карты.

```sh
cd /workspace/hoi4
npm ci --cache /tmp/hoi4-npm-cache
npm run dev -- --port 5173
```

`npm run build` создаёт production-сборку в `dist`. Для проверки сборки: `npm run preview -- --port 4173`. Серверная часть, ключи API и внешняя база данных не требуются. Карта и шрифты поставляются локально; после сборки игре не нужен доступ к внешним сервисам.

## Управление

- Страна выбирается в левом верхнем углу; это начинает новую кампанию.
- **Пробел** или кнопка ▶ переключают паузу. Клавиши **1–5** меняют скорость. На скорости 1× за реальную секунду проходит 6 игровых часов.
- Время влияет на движение, бой, подготовку войск, исследования и пополнение ресурсов. Во время паузы можно отдавать приказы.
- Выберите подразделения слева или на карте и нажмите на страну назначения. Для атаки сначала объявите войну в дипломатии.
- Пехота, артиллерия и танки пересекают общую границу. Для морского вторжения нужен флот и побережье; доступность маршрутов упрощена.
- Истребители и бомбардировщики действуют в радиусе 2 500 км. Корабли поддерживают операции на побережье. Без сухопутных войск территорию захватить нельзя.
- Военная мощь зависит от количества, здоровья, организации, технологий и топлива. Противник защищается и контратакует каждые 72 игровых часа.
- Производство резервирует людей и снаряжение. Одновременно готовятся до 6 подразделений. Отмена возвращает людей и 75% снаряжения.
- Доступны исследования вооружения, промышленности и авиационной доктрины; одновременно исследуется одна технология.
- Отношения +60 позволяют заключить союз. Объявление войны стоит 50 влияния и уменьшает стабильность на 3%.
- Кампания автоматически сохраняется каждые 5 секунд в `localStorage`. Сохранение и загрузка доступны через меню. Загрузка всегда ставит время на паузу.
- Перетаскивание перемещает карту, колесо меняет масштаб. Справа доступны политический, военный и дипломатический слои, масштабирование, переход к своей стране и обзор мира.

## Историческая карта

Источник: **CShapes 2.0**, Nils B. Weidmann, Guy Schvitz, Luc Girardin; вариант Gleditsch–Ward (GW), срез **1 января 1936 года**, с зависимыми территориями. В карте 170 территорий и 69 независимых государств. Австрия и Чехословакия независимы; показаны Восточная Пруссия, восточные границы Польши и европейские колониальные владения.

CShapes — исследовательский набор с собственной кодировкой признания государств. Некоторые непризнанные, спорные и фактически подконтрольные образования (например, Маньчжоу-го) не выделены отдельно. Отображение не является утверждением об исторической принадлежности спорных территорий. Численность армий, экономика, идеологии, флаги и ход войны упрощены: это игровой баланс, а не реконструкция исторических событий. Боевые территории соответствуют странам/зависимым владениям, провинциального деления нет.

Исходный пакет: <https://github.com/cran/cshapes>, commit `54840534d9a82cfd01caf1021f85933e701e8318`. Для генерации отобраны записи по датам, приведены направления колец к формату D3, координаты округлены до 4 знаков и вычислены соседние территории по топологии.

Воспроизводимое обновление из того же источника (проверяет SHA-256):

```sh
python3 scripts/fetch-map.py
```

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

10 тестов симуляции проверяют паузу, затраты и завершение подготовки, отмену, исследования, войну и захват территории, авиационную поддержку, дипломатию, ответ противника, сохранения и историческую географию. Браузерные тесты Playwright проверяют время, все роды войск, производство, исследования, сохранение, приказы, масштаб, выбор страны и мобильный интерфейс.

Браузерные тесты используют Chromium из `/usr/bin/chromium`. Другой путь можно указать переменной `BROWSER_EXECUTABLE`. Для системы без Chromium установите браузер и укажите путь к нему. Playwright запускает сервер самостоятельно, если он ещё не запущен.
