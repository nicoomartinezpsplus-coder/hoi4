# IRONFRONT · 1936 — Godot Edition

Самостоятельная настольная стратегия на **Godot 4.6.3**, GDScript, 2D, рендерер Compatibility. Для игры не нужны браузер, Node.js, npm или .NET.

## Запустить готовую игру в Windows

1. Скачайте [IRONFRONT-Godot-Windows.zip](https://github.com/nicoomartinezpsplus-coder/hoi4/raw/refs/heads/main/downloads/IRONFRONT-Godot-Windows.zip).
2. Распакуйте архив через «Извлечь всё».
3. Дважды нажмите **IRONFRONT.exe**.

Нужны Windows 10/11 x64 и видеодрайвер с поддержкой OpenGL 3.3. Все данные встроены в приложение. В архиве есть `START-HERE.txt` и тексты лицензий. Это неподписанная сборка собственного проекта, а не установщик.

Windows-сборка экспортирована из Godot на Linux. Нативная симуляция, интерфейс и экспортированная Linux-сборка проверяются в этой среде; запуск на настоящей Windows здесь не проверялся.

## Открыть исходники в Godot

1. Установите стандартную версию **Godot 4.6.3 или новее** с [godotengine.org](https://godotengine.org/download/windows/). Версия .NET не требуется.
2. Скачайте ZIP всего репозитория и распакуйте.
3. В менеджере проектов Godot нажмите **«Импортировать»**, выберите **godot/project.godot**.
4. Откройте проект, дождитесь импорта ресурсов и нажмите **F5**.

`project.godot` находится во вложенной папке `godot`, а не рядом с `package.json`. Команды npm для запуска Godot не нужны. Папка `.godot` генерируется редактором и не включена в репозиторий.

## Управление и механика

- **Пробел / ▶** — пауза; **1–5** — скорость; **F5** — сохранить; **F9** — загрузить. На 1× за секунду проходит 6 игровых часов. Во время паузы приказы принимаются.
- Выберите страну сверху для новой кампании. Доступны 69 независимых государств и Данциг. По умолчанию — Германия.
- Выберите подразделения слева или нажмите на счётчик войск на карте. Можно выбрать несколько, снять выбор или отменить приказы. Армия, авиация и флот имеют отдельные вкладки.
- Нажмите на точку города или его область: справа появятся текущий владелец, промышленность, гарнизон, порт и список городов страны. Если войска выбраны, клик отдаёт приказ.
- Перед атакой объявите войну в дипломатии. Пехота, артиллерия и танки захватывают города; авиация поддерживает бой в радиусе 2 500 км, корабли действуют в портах. Авиация и флот без сухопутных войск не занимают области.
- Наземный маршрут проходит через свои/союзные области и заканчивается на соседнем вражеском городе. Перескакивать через вражеские области нельзя. Для морской переброски нужен флот, доступный порт отправления и порт назначения не дальше 6 500 км.
- Захват одного города передаёт только его область и заводы. Противник защищается и контратакует каждые 72 игровых часа. Повторные захваты не создают дополнительные заводы.
- Государство капитулирует после потери всех городов, включая зависимые территории. Если проигрывает игрок, время останавливается; новую кампанию можно начать в меню.
- Производство резервирует людей и снаряжение. Одновременно готовятся до 6 подразделений; отмена возвращает людей и 75% снаряжения. Корабли появляются в подконтрольных портах; потеря последнего порта приостанавливает их подготовку. Захваченный порт позволяет строить флот даже стране без начального выхода к морю.
- Исследования усиливают вооружение, промышленность и авиацию. Доступен один проект за раз. Отношения +60 позволяют заключить союз; объявление войны стоит 50 влияния.
- Перетаскивание мышью — обзор карты; колесо и +/− — масштаб; «Домой» — своя страна; «Мир» — обзор мира. Есть политический, военный и дипломатический слои и переключатель городов.

## Сохранения

Игра пишет `campaign.json` в `user://`, автоматически каждые 10 секунд и при нормальном закрытии окна. В Windows это обычно `%APPDATA%\Godot\app_userdata\IRONFRONT · 1936\`. Точная папка доступна через **Меню → Открыть папку сохранений**. Запись выполняется через временный файл и замену; загрузка ставит время на паузу. Кнопка «Новая кампания» заменяет текущую кампанию.

Сохранения браузера не читаются автоматически: у браузера и настольного приложения разные хранилища. Для переноса откройте браузерную игру, в консоли разработчика выполните:

```js
const text = localStorage.getItem('ironfront-campaign-v1');
const a = document.createElement('a');
a.href = URL.createObjectURL(new Blob([text], {type: 'application/json'}));
a.download = 'campaign.json';
a.click();
URL.revokeObjectURL(a.href);
```

Затем в Godot-игре нажмите **Меню → Импортировать JSON-сохранение v2** и выберите файл. Поддерживаются сохранения браузерной версии с городами (v2); самые старые v1 сначала откройте в обновлённой браузерной версии для преобразования.

## Данные и устройство проекта

- `scripts/campaign.gd` — самостоятельная симуляция без зависимостей от сцен: ресурсы, маршруты, сражения, производство, исследования, дипломатия, противник и сохранения.
- `scripts/main.gd` и `scenes/main.tscn` — нативный интерфейс Godot и игровые часы.
- `scripts/world_map.gd` — обзор, масштаб, выбор областей и войск. `map_geometry.gd` хранит статическую карту в командах CanvasItem; `map_overlay.gd` рисует движущиеся войска, приказы и города.
- `data/game.json`, `cities.json`, `map.json` — поставляемые данные. Полигоны заранее проецируются и разбиваются на треугольники с учётом отверстий и линии перемены дат. При изменении времени неподвижная геометрия карты не пересоздаётся.
- `tests/test_campaign.gd` — 33 проверки игровой логики с ненулевым кодом выхода при ошибке.
- `export_presets.cfg` — Windows x64 и Linux x64, со встроенным игровым пакетом.

Источник внешних границ — **CShapes 2.0**, вариант GW, срез **1 января 1936 года**: 170 территорий, 69 независимых государств. Карта имеет ограничения признания спорных образований, включая отсутствие отдельного Маньчжоу-го. 479 реальных городов используют представительный каталог, а не полный перечень населённых пунктов. Внутренние области — игровые диаграммы Вороного, обрезанные по историческим границам; это не точные исторические административные границы и не копия провинций HOI4. Войска и экономика упрощены. Полный источник и происхождение данных — в корневом README.

## Разработка и сборка

Запуск уже поставленного проекта не требует генерации данных. При изменении карты или баланса разработчик может из корня репозитория выполнить `npm ci`, затем `npm run godot:data`. Данные воспроизводимо берутся из той же карты и симуляции браузерного прототипа; генератор использует D3 и Earcut.

В Linux/облаке:

```sh
python3 scripts/install-godot-tools.py
bash scripts/godot.sh --headless --editor --path godot --import
bash scripts/godot.sh --headless --path godot --script tests/test_campaign.gd
bash scripts/godot.sh --path godot
```

Установщик закрепляет Godot 4.6.3 и проверяет SHA-512 официальных архивов. Инструменты, шаблоны экспорта и XDG-папки хранятся в `/tmp/ironfront-godot` (путь можно переопределить `IRONFRONT_GODOT_DIR`). На сервере без дисплея доступен запуск `--headless --quit-after 5`. Проверка настоящего интерфейса выполняется с дисплеем командой `bash scripts/godot.sh --path godot --audio-driver Dummy -- --ui-test`; она проверяет ввод мышью/пробелом, паузу, производство, захват Зальцбурга и сохранение австрийской Вены, затем завершает процесс.

Экспорт через Godot: **Проект → Экспорт → Windows Desktop → Экспортировать проект**. При запросе установите шаблоны экспорта той же версии редактора через **Редактор → Управление шаблонами экспорта**. Для командной сборки:

```sh
mkdir -p godot/builds/windows godot/builds/linux
bash scripts/godot.sh --headless --path godot --export-release "Windows Desktop" builds/windows/IRONFRONT.exe
bash scripts/godot.sh --headless --path godot --export-release "Linux Desktop" builds/linux/IRONFRONT.x86_64
python3 scripts/package-godot.py
```

GitHub Actions повторяет проверку и обе сборки; ZIP доступны также в артефакте `IRONFRONT-Godot-desktop` успешного запуска workflow. Наличие файла workflow не означает, что удалённый запуск уже прошёл.
